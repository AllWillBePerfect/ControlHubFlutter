# ControlHub

Приложение для Android, которое переключает вход монитора с телефона.

Работает через DDC/CI, поэтому монитор должен его поддерживать. Обычно это включается в меню монитора.

## Как пользоваться

На компьютере, к которому подключен монитор, должен быть запущен агент ControlHub. Приложение находит его в локальной сети, после этого нужно ввести токен из agent.properties.

Список входов приложение получает от монитора. Входы можно переименовать и скрыть через кнопку настроек на карточке монитора.

## Сборка

    cd app
    flutter build apk --release
