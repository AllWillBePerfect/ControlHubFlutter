# Changelog

## 1.2.0 (2026-10-17)

### Добавлено
* Индикатор связи с агентом рядом с названием источника: зеленый, если агент отвечает, красный, если нет.

### Изменено
* Новый идентификатор приложения com.awbp.controlhub. Обновиться поверх 1.1.0 не получится: старую версию нужно удалить, источники добавить заново.
* Название приложения на телефоне теперь ControlHub.
* Релизная сборка подписана собственным ключом.

### Исправлено
* При ручном добавлении источника подставлялся неверный порт по умолчанию.

## 1.1.0 (2026-10-17)

### Добавлено
* В настройках входов под переименованным входом показывается его исходное название.
* При переименовании поле открывается пустым, исходное название видно подсказкой.

## 1.0.0 (2026-10-16)
